# 团队项目工作台接入

页面在现有 GitHub Pages 的 `/workspace/`，账号和真实任务存放在独立 Supabase 项目。这个目录不出现在博客主导航；页面公开可加载，项目数据由数据库成员权限保护。`noindex` 只减少搜索收录，不是权限控制。

尚未配置时可以预览虚构示例；示例不上传、不跨设备保存。接入后，成员通过邮箱与密码登录，共享同一份任务，每 20 秒及切回页面时自动刷新，也可手动刷新。无需每次更新任务都提交 GitHub。

## 1. 创建云端项目

1. 在 <https://supabase.com/dashboard> 登录并创建一个独立项目。可先选 Free，不需要为了此页面开通付费档。数据库密码由你在服务商页面设置，不要放进聊天或仓库。
2. 在 SQL Editor 打开仓库的 `supabase/schema.sql`，完整执行。该脚本创建工作台专用表、读取策略和写入函数，不包含任何真实项目记录。
3. 表格必须保持启用 RLS。不能为了解决登录或读取问题关闭 RLS，也不要授予匿名用户读写权限。

## 2. 配置成员账号

1. 在 Authentication 的用户注册设置中关闭公开注册；保留 Email 登录。
2. 在 Authentication → Users 使用 Add user 创建本人及成员账号。用安全渠道让成员获得初始密码，成员首次登录后通过工作台右上角“账号”设置自己的密码。账号后台由负责人管理。
3. 在 Authentication → URL Configuration 将 Site URL 设置为 `https://shaiolssss.github.io/shaiol/workspace/`，并将同一地址加入允许的 Redirect URLs。需要本地调试时，额外加入 `http://127.0.0.1:4174/shaiol/workspace/`。
4. 密码重设需要可用的 Auth 邮件服务。Supabase 默认邮件服务有收件人及速率限制，给团队正式使用前按官方文档配置自己的 SMTP；此步骤没有完成时，可以先使用后台创建的邮箱／密码账号，不依赖邮件邀请或忘记密码流程。

工作台不开放自行注册。账号存在也不代表能看见所有项目，仍需加入具体项目。前台“加入已有账号”只添加项目成员关系，不创建账号或发送邀请邮件。

## 3. 连接公开客户端配置

从 Supabase 项目的 Connect／API Keys 页面取得项目 URL 和 **publishable key**（旧项目也支持 `anon` key）。修改 `public/assets/planner-config.json`：

```json
{
  "supabaseUrl": "https://YOUR_PROJECT.supabase.co",
  "publishableKey": "YOUR_PUBLISHABLE_KEY"
}
```

这两项是浏览器连接项目用的公开配置。真实权限取决于 RLS 与已登录用户，而不是隐藏这两个值。**禁止使用 `sb_secret_…`、`service_role`、数据库密码或连接字符串。** 配置提交到博客 `main`，由 GitHub Actions 发布；后续更新任务不再修改这个配置。

## 4. 创建实际项目

1. 用本人账号登录工作台，点击“新建项目”，填写名称及阶段。
2. 创建者自动成为项目负责人。打开“项目成员”，输入已在账号后台创建的成员邮箱与显示名称。
3. 成员登录后能看到已加入的项目，创建／编辑任务、更新状态与执行进度、归档和恢复任务；只有负责人能修改项目阶段或加入新成员。
4. 真实项目刚创建时没有示例任务，进度为 0；不要把演示项目里的日期和份量直接当作实际排期。

负责人可在成员列表移出成员，其负责的任务保留并改为未分配。数据库权限立即撤销；对方工作台在下一次同步时关闭对应项目。需要时可以重新加入。不要使用删除账号来代替移出项目。

## 进度口径与协作

- 总执行进度 = 所有未归档普通任务的 `工作量 × 进度` 之和，除以普通任务工作量之和；里程碑不参与加权。
- “验收完成”只统计状态为“已完成”的普通任务；执行进度达到 100% 可以先停在“待验收”。
- 筛选只影响当前视图，顶部总览仍统计整个项目，避免筛选后误以为项目总进度变化。
- 前置关系仅提示阻塞并在甘特图连线，不自动改动其他任务的排期，也不阻止成员登记真实发生的进度。
- 保存时校验版本；冲突会保留表单输入并提示刷新，不静默覆盖其他成员。项目阶段同样校验版本。
- 归档可恢复；仍被其他任务依赖的任务需先解除依赖，才能归档。
- 导出的 JSON 包含项目与成员信息，作为团队内备份保存，不要提交到公开博客。

## 上线核实

实际云端配置完成后，至少使用三个身份核实：未登录访客看不到任务；未加入该项目的账号看不到该项目；项目成员可创建并更新任务。再用两个已加入的账号同时编辑同一任务，确认后提交者收到冲突提示。仅完成页面构建，不代表云端权限已配置成功。

## 费用与服务限制

可从免费档开始。当前免费档提供两个活跃项目、每项目 500 MB 数据库；低活动项目可能在一周后暂停，需要负责人在后台恢复。费用、配额和邮件限制以服务商最新说明为准。
